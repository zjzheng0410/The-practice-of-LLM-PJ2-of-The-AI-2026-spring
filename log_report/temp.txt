# valid_v2 之后的训练与评估命令记录

前提：

- 已经进入 conda 环境，不再写 `conda run -n ...`。
- 以下命令都在 `Math_Solver` 目录下执行：

```bash
cd /home/zjzheng/Lesson/AI_2026_springsemester/PJ2/Math_Solver
unset TQDM_DISABLE
export PYTHONUNBUFFERED=1
```

## 生成 valid_v2

```bash
python -m data_preprocess.prepare_data \
  --input-file data/raw_data/train.json \
  --output-dir data/clean_data \
  --version v2 \
  --valid-size 1000 \
  --seed 20260530
```

检查切分报告：

```bash
python -m json.tool data/clean_data/split_report_v2.json
```

`train_valid_overlap_group_count` 必须为 `0`。

## v2 训练模板

```bash
python -u qwen_ft.py \
  --train-file data/clean_data/train_sft_v2.json \
  --valid-file data/clean_data/valid_sft_v2.json \
  --output-dir output/clean-006 \
  --experiment-id clean-006 \
  --epochs 5 \
  --learning-rate 1e-4 \
  --max-length 384 \
  --lora-r 8 \
  --save-steps 1000
```

训练阶段只产出候选 checkpoint；最终选择以 `valid_v2` 生成准确率为准，不再引用 `trainer_state.json` 的 `best_model_checkpoint`。

## 多 checkpoint 评估模板

```bash
python -m evaluation.evaluate_checkpoints \
  --experiment-dir output/clean-005 \
  --experiment-id clean-005 \
  --valid-file data/clean_data/valid_sft_v2.json \
  --max-new-tokens 32 \
  --output-dir eval_result \
  --split-name valid_v2
```

输出位置：

```text

  checkpoint-1000/
```

## 同步到另一台机器评估

最少同步这些路径：

```text
answer_utils.py
generation.py
infer.py
evaluation/
data/clean_data/valid_sft_v2.json
output/<experiment>/checkpoint-<step>/
```

远端进入同一环境和 `Math_Solver` 目录后，使用 `python -m evaluation.evaluate_checkpoint` 或 `python -m evaluation.evaluate_checkpoints` 执行评估。
