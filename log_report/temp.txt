## 如何 eval 已训练好的 clean-001

当前 `qwen_ft.py` 开启了 `load_best_model_at_end=True`，但磁盘上需要手动指定要评估的 checkpoint。先从 `trainer_state.json` 里看 best checkpoint：

```bash
python - <<'PY'
import json
from pathlib import Path

state = json.loads(Path("output/clean-001/checkpoint-3410/trainer_state.json").read_text())
print("best_model_checkpoint =", state["best_model_checkpoint"])
print("best_metric(eval_loss) =", state["best_metric"])
print("global_step =", state["global_step"])
PY
```

本机当前 clean-001 记录显示 best checkpoint 是：

```text
output/clean-001/checkpoint-1000
```

评估 clean-001 的 best checkpoint：

```bash
python -u eval.py \
  --checkpoint output/clean-003/checkpoint-1000 \
  --valid-file data/clean_data/valid_sft_v1.json \
  --experiment-id clean-003 \
  --max-new-tokens 32 \
  --output-dir eval
```

如果也想对比 clean-001 最后一个 checkpoint：

```bash
python -u eval.py \
  --checkpoint output/clean-001/checkpoint-3410 \
  --valid-file data/clean_data/valid_sft_v1.json \
  --experiment-id clean-001-final \
  --max-new-tokens 32 \
  --output-dir eval
```

## clean-002/003/004 训练完成后的 eval 模板

每个实验训练完成后，把下面的 `EXP` 改成对应实验编号；`BEST_CKPT` 用该实验最后一个 checkpoint 里的 `trainer_state.json` 查出来。

```bash
EXP=clean-002
LAST_CKPT=$(find "output/${EXP}" -maxdepth 1 -type d -name 'checkpoint-*' | sort -V | tail -1)
BEST_CKPT=$(python - <<PY
import json
from pathlib import Path
state = json.loads((Path("${LAST_CKPT}") / "trainer_state.json").read_text())
print(state["best_model_checkpoint"])
PY
)
echo "LAST_CKPT=${LAST_CKPT}"
echo "BEST_CKPT=${BEST_CKPT}"

python -u eval.py \
  --checkpoint "${BEST_CKPT}" \
  --valid-file data/clean_data/valid_sft_v1.json \
  --experiment-id "${EXP}" \
  --max-new-tokens 32 \
  --output-dir eval
```

需要评估 `clean-003` 或 `clean-004` 时，只改第一行：

```bash
EXP=clean-003
# 或
EXP=clean-004
```

## 如果要同步到另一个工作区/机器再 eval

eval 依赖的不只是 `eval.py`，还依赖最新的 `infer.py`、`answer_utils.py`、验证集和对应 checkpoint。同步前确认目标工作区也在 `Math_Solver` 根目录结构下。

最少需要同步这些路径：

```text
answer_utils.py
infer.py
eval.py
data/clean_data/valid_sft_v1.json
output/clean-001/checkpoint-1000/
```

如果在远端机器 eval，把 `<REMOTE>` 和 `<REMOTE_MATH_SOLVER_DIR>` 替换成实际地址：

```bash
rsync -av --relative \
  answer_utils.py infer.py eval.py \
  data/clean_data/valid_sft_v1.json \
  output/clean-001/checkpoint-1000 \
  <REMOTE>:<REMOTE_MATH_SOLVER_DIR>/
```

到远端后进入同一个 conda 环境和 `Math_Solver` 目录，再运行：

```bash
python -u eval.py \
  --checkpoint output/clean-001/checkpoint-1000 \
  --valid-file data/clean_data/valid_sft_v1.json \
  --experiment-id clean-001 \
  --max-new-tokens 32 \
  --output-dir eval
```

注意：如果只有一张 GPU，不建议一边训练 clean-002 一边 eval clean-001，容易显存不足；有空闲 GPU 时可以另开终端并指定 GPU，例如：

```bash
CUDA_VISIBLE_DEVICES=1 python -u eval.py \
  --checkpoint output/clean-001/checkpoint-1000 \
  --valid-file data/clean_data/valid_sft_v1.json \
  --experiment-id clean-001 \
  --max-new-tokens 32 \
  --output-dir eval
```
